#📊 Functional Treat-Data Analyzer and Transformer Program

##📝 Project Description

The Data Analyzer and Transformer Program is a Python-based, menu-driven application designed to perform various operations on a 1D array of integer data.

The program allows users to enter data and perform useful operations such as calculating the minimum, maximum, sum, average, factorial, filtering values based on a threshold, and sorting data in ascending or descending order.

This project also demonstrates important Python programming concepts such as functions, recursion, lambda functions, built-in functions, multiple return values, *args, **kwargs, and exception handling. 🐍💻

##✨ Features

###📝 Input Data

Accepts integer values from the user.

Stores the values in a 1D list.

###📊 Display Data Summary

Displays the total number of elements.

Finds the minimum value.

Finds the maximum value.

Calculates the sum.

Calculates the average.

###🔢 Calculate Factorial

Calculates the factorial of a non-negative integer.

Uses recursion.

###🔍 Filter Data

Filters values greater than or equal to a user-defined threshold.

Uses a lambda function.

###↕️ Sort Data

Sorts data in ascending order.

Sorts data in descending order.

###📈 Display Dataset Statistics

Calculates minimum, maximum, sum, and average.

Demonstrates multiple return values.

Uses *args and **kwargs.

###⚠️ Input Validation

Handles invalid user input using exception handling.

Prevents the program from crashing due to invalid values.

##🚀 How to Run
Step 1: Install Python

Make sure Python 3 is installed on your computer.

Check the installed version using:

python --version

Step 2: Save the Python File

Save the program as:

data_analyzer.py

Step 3: Open Terminal

Open Command Prompt or Terminal and navigate to the project folder.

Step 4: Run the Program

Execute the following command:

python data_analyzer.py

Step 5: Use the Menu

The program will display:

Welcome to the Data Analyzer and Transformer Program

Main Menu:
1. Input Data
2. Display Data Summary (Built-in Functions)
3. Calculate Factorial (Recursion)
4. Filter Data by Threshold (Lambda Function)
5. Sort Data
6. Display Dataset Statistics (Multiple Return Values)
7. Exit Program


Enter a number from 1 to 7 to perform the desired operation.
